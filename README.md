# 🌋 Organizador de Rutas - App de Travesías

Aplicación diseñada para la gestión y logística de rutas off-road. Optimizado para expediciones tipo **Suzuki Jimny** y entusiastas del 4x4.

## 📱 Vista Previa
![Login App](assets/app.png)<br>
*Pantalla de acceso con sistema de código de seguridad de 4 dígitos.*

## 🚀 Características
- **Acceso Privado:** Sistema de login mediante código de 4 dígitos con efecto visual de celdas.
- **Gestión de Ruta:** Información dinámica sobre fecha, hora, punto de reunión y equipo obligatorio.
- **Lista de Asistencia:** Registro de participantes y vehículos en tiempo real.
- **Galería de Fotos:** Espacio para compartir las capturas de la aventura (imágenes optimizadas para bajo consumo de datos).
- **Modo Admin:** Panel de control para editar el nombre de la ruta, links de WhatsApp, ubicación de Google Maps y personalización de fondo.
- **Look Off-Road:** Interfaz en "Modo Oscuro" nativo con acentos naranja neón y verde foresta.
